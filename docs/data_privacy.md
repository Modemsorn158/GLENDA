# Research image handling for the local demo

The demo is for synthetic or appropriately authorized, de-identified images only. It is not a clinical service. Before using any real research image, the responsible team must confirm consent or another valid basis, dataset terms, who may access the computer and the permitted retention period. This repository does not provide those approvals or enforce role-based access.

Dataset images exist in older commits reachable through the repository's Git history, although they are absent from the current checkout. `.gitignore` and deletion from the current tree do not remove them from history or existing clones. The repository owner and data custodian should review hosting visibility, dataset terms and any required remediation. Rewriting shared history or changing visibility requires a separate, coordinated decision; neither has been done by this update.

The demo uses localhost and does not request a public Gradio sharing link. Localhost is not access control: other local users, operating-system administrators, malware or backups may still access data. Work in an appropriately access-restricted and encrypted location with a user account and storage policy approved by the data custodian. The software does not verify encryption, permissions or consent. Upload-size limits are not configured by this project; restrict access and apply an appropriate external limit before accepting inputs.

Each session creates a `gradio_uploads_...` folder next to its checkpoint. Normal shutdown attempts to remove that session's folder. Abrupt termination or system failure can leave data behind, and library/OS caches, backups or other copies may exist elsewhere. At startup the demo warns if matching directories already exist. They may belong to an active session; the warning does not identify ownership or delete anything.

Before and after use, review the checkpoint directory and other applicable caches under the approved local policy. Coordinate with other users before removing a session directory, inspect only data you are authorized to access, and delete only folders confirmed to be abandoned and no longer needed. The historical `gradio_tmp` folder used by an older demo must be reviewed separately. Ordinary deletion is not guaranteed secure erasure. Record any retention or incident handling according to the data custodian's procedures.
