# Protocol and open limitations

## Intended evaluation

Before selecting models, freeze one grouped holdout and use only the development folds for model selection, early stopping and threshold selection. The current split generator uses the first shuffled five-way `StratifiedGroupKFold` partition as the holdout and a separate five-way partition for development. The seed and source file hashes are recorded. No images are subsampled. Report the resulting distribution rather than describing it as clinical prevalence; a grouped split can differ substantially from the overall frame distribution. Groups are not independent patients where negative case identifiers are unavailable.

After the one-epoch feasibility ablation, the short tuning budget in `configs/tuning.json` compares weighted frozen EfficientNet-B0 at learning rate 0.0003 with weighted partial fine-tuning at 0.0001 for at most three epochs. These candidates were chosen after examining development-only feasibility results, not before the exploratory work; their cross-validation estimates therefore do not represent an unbiased nested evaluation. Select the completed candidate with the highest mean development-fold average precision, breaking exact ties in favor of the first configuration. If any required fold fails, do not select from incomplete results. Choose the decision threshold by pooled out-of-fold F1 only after selecting the candidate, and use the median fold-best epoch count for the final fit. Evaluate the held-out split once after these choices are fixed. The modest budget limits conclusions about convergence.

Link all frames with the same known case, video, exact SHA-256 digest, or difference-hash screening candidate before splitting. The dHash threshold of three is a reproducible, conservative screening rule, not a diagnosis of duplication; a visual review found some candidate pairs are plainly different. It does not detect all transformed or near-identical images. It can merge independent groups, and unknown patient relationships remain a leakage threat. Seek the dataset owners' case mapping and use stronger duplicate review before claiming patient independence.

The split manifest and input inventory are fingerprinted, but the trainer does not rehash raw image bytes at every run. Before reproducing an experiment, rerun the read-only inventory into a separate output directory and compare its `inventory.csv` SHA-256 with the value in the saved split protocol. The sequence-bound audit was repeated and reproduced the original inventory hash in this environment.

## Historical report

The supplied 15-page report describes a 114-frame test set with 38 positive and 76 negative images, and a 1:2 sampling ratio. That is not 10% of the 13,811 released frames. It reports grouped folds and a later grouped internal validation correction, but its stated scores are historical claims, not verified outputs of this rebuild. It also acknowledges the altered test prevalence and lack of ROC/PR curves. Its optimizer and learning-rate interpretations should not be treated as causal without controlled comparisons. Thai text extraction is imperfect; interpretation should be checked against the original pages. The preserved repository's original `main` commit contains four `src/data` files and no training or evaluation scripts, so the report's reported model-selection and test execution cannot be independently reconstructed from that snapshot. Its `splits.py` groups records into case and video lists but does not itself construct or validate train/test partitions.

## Status

CPU and GPU smoke runs used eight development frames and one epoch; these verify execution only. A one-epoch frozen ImageNet EfficientNet-B0 feasibility configuration and a matched class-weighted ablation have completed all five development folds on the RTX 4050. Their per-fold results and descriptive variation are generated in `reports/feasibility_results.md` and `reports/weighting_feasibility.md`. They are exploratory development results, not test results or evidence of convergence. A longer hyperparameter search, final model and test evaluation remain incomplete. A split manifest alone does not make the evaluation independent, clinically representative, or prospectively locked. Model and threshold choices must be fixed without using test predictions. External data are required for an external validation claim.
